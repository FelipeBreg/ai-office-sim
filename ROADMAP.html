BUILD PRINCIPLES

  1. Dependency order, not priority order. Every phase builds on the previous. No phase requires work from a later phase.
  2. Ship and test each phase independently. After each phase, the system should be testable. Don't build Phase 3 features into Phase 1 code.
  3. Maximum usability over cost savings. Use the best models. Keep all memory layers. Don't cut features to save API cost.
  4. One vendor. All LLM calls use Anthropic Claude (Opus for reasoning, Haiku for extraction/triage). No OpenAI dependency for core features.
  5. Schema changes via raw SQL. drizzle-kit is broken in WSL. All migrations run via node -e with the postgres driver against Neon.
  6. Test in the worker. Agent execution code lives in apps/worker. Test by triggering agents via the UI "Run" button or BullMQ enqueue.
  7. Exact file paths. Every task lists the files to modify. No guessing.
